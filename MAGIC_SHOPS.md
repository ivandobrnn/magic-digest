# Магазины фокусов

Мировой каталог для Telegram-дайджеста. 163 сайтов, 36 стран и территорий. Обновлено 16.11.2026.

Включены интернет-магазины, производители и оптовые поставщики с каталогами реквизита. Регион обозначает страну или территорию магазина по данным каталога. Пустая ячейка в колонке «Новинки» означает, что отдельная витрина ещё не подтверждена. Статус «Сайт ответил» означает успешный HTTP-ответ при проверке главной страницы. Доступность из GitHub Actions проверена для источников с отметкой «В дайджесте».
